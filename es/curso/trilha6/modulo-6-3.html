🧬 Anatomía de una skill reutilizable

Toda skill bien hecha tiene las las mismas partes. Memoriza este esqueleto y crearás nuevas skills en minutos.

SKILL: {{nome_da_skill}}            # v1.0
PAPEL:    Você é {{especialista_em_X}}.
OBJETIVO: {{o_que_a_skill_entrega}}.

ENTRADA (variáveis):
  - {{var_1}} : descriçêo
  - {{var_2}} : descriçêo

REGRAS:
  - {{regra_1}}
  - {{regra_2}}
  - Quando nêo tiver certeza: {{fallback}}.

FORMATO DE SAÍDA:
  {{schema_ou_estrutura}}

EXEMPLO (few-shot):
  entrada -> {{exemplo_in}}
  saída   -> {{exemplo_out}}

"""
{{entrada}}
"""

Siempre que vayas a transformar un prompt suelto en algo reutilizable y versionable. Es la plantilla de las cuatro skills siguientes.

Puntos de personalización

  • PAPEL e REGLAS — específicos del dominio
  • FORMATO — esquema de salida
  • EJEMPLO — 1–2 casos del cliente

📨 Skill: clasificar y dirigir correos/mensajes

Lee un mensaje, lo clasifica en categorías fijas y decide el destino.

SKILL: Classificar & Rotear            # v1.0
PAPEL: Você é um classificador de mensagens de atendimento.

REGRAS:
  - Categorias permitidas: {{categorias}}   // ex: pedido, dúvida, reclamaçêo, spam
  - Escolha SOMENTE uma categoria da lista.
  - Dê uma confiança de 0 a 1.
  - Se confiança < 0.6, destino = "humano".

FORMATO DE SAÍDA (apenas JSON):
  { "categoria": string, "confianca": number,
    "destino": string, "resumo": string }

Mensagem:
"""
{{mensagem}}
"""

Cuándo usar

Clasificación de la bandeja de entrada, WhatsApp y tickets. Colócala al inicio de cualquier flujo que necesite decidir «a dónde va esto».

Puntos de personalización

  • {{categorias}} — las del cliente
  • Umbral de confianza (0.6) según la tolerancia al error
  • Mapa de categoría → destino en el flujo

📄 Skill: resumir y extraer datos de documentos

Recibe un documento largo y devuelve un resumen + campos estructurados, citando la fuente.

SKILL: Resumir & Extrair Documento     # v1.0
PAPEL: Você extrai dados de documentos com precisêo.

REGRAS:
  - Use SOMENTE o que está no documento. Nêo infira.
  - Para cada campo extraído, cite o trecho de origem.
  - Campo ausente = null.

FORMATO DE SAÍDA (apenas JSON):
  {
    "resumo": string,                  // 3 a 5 linhas
    "campos": { {{campos_alvo}} },     // ex: "valor", "vencimento", "partes"
    "citacoes": { "campo": "trecho..." }
  }

Documento:
"""
{{documento}}
"""

Cuándo usar

Contratos, facturas, propuestas, correos largos. Para documentos grandes, divídelos en partes (chunks) y procésalos por separado.

Puntos de personalización

  • {{campos_alvo}} — qué extraer
  • Tamaño del resumen
  • Activar/desactivar citas

📈 Skill: generar un informe a partir de una hoja de cálculo

Recibe datos tabulares y genera un informe narrativo con puntos destacados y recomendaciones.

SKILL: Relatório de Planilha            # v1.0
PAPEL: Você é um analista que vira dados em insight executivo.

DADOS (CSV/tabela):
"""
{{dados}}
"""
Período: {{periodo}}   ·   Métricas-chave: {{metricas}}

REGRAS:
  - Baseie-se SÓ nos números fornecidos.
  - Destaque variações relevantes (subiu/caiu) com o número.
  - Tom executivo, direto. Sem jargêo.

FORMATO DE SAÍDA (markdown):
  ## Resumo (2 linhas)
  ## Destaques (3 bullets com números)
  ## Pontos de atençêo (1-2 bullets)
  ## Recomendações (2 ações concretas)

Cuándo usar

Informe semanal/mensual automático a partir de una hoja de cálculo de ventas, finanzas o tráfico. Una entrega que el cliente percibe como valiosa de inmediato.

Puntos de personalización

  • {{metricas}} — qué importa
  • Secciones del informe
  • Tono (ejecutivo / técnico)

🤖 Skill: responder preguntas frecuentes con una base de conocimiento (RAG)

Responde preguntas usando solo la base de conocimientos proporcionada: el patrón RAG que evita las alucinaciones.

SKILL: FAQ com base (RAG)               # v1.0
PAPEL: Você é o atendente de {{empresa}}. Responde com base na fonte.

BASE DE CONHECIMENTO (trechos recuperados):
"""
{{contexto_recuperado}}
"""

REGRAS:
  - Responda SOMENTE com o que está na base acima.
  - Se a resposta nêo estiver na base, diga:
    "Nêo tenho essa informaçêo, vou te encaminhar para um atendente."
  - Cite o trecho usado entre colchetes [fonte].
  - Tom: {{tom}}   // ex: cordial e objetivo

Pergunta do cliente:
"""
{{pergunta}}
"""

✓ Qué hace que funcione

  • ✓"Solo con la base" + una frase de "no sé" evita inventar
  • ✓Recuperar primero los fragmentos adecuados (búsqueda) es la mitad del trabajo
  • ✓Citar la fuente genera confianza y facilita la auditoría

✗ Donde se rompe

  • ✗Base mal recuperada = respuesta incorrecta con confianza
  • ✗Sin la frase «no sé», la IA inventa
  • ✗Un contexto demasiado grande diluye la respuesta

💡 Consejo práctico

La calidad del RAG depende más de la recuperación (qué fragmentos inyectas) que del prompt. Empieza con una base pequeña y bien organizada antes de escalar.

🔁 Cómo adaptar y versionar tus skills

La reutilización es lo que permite escalar un negocio de automatización. Nunca empiezas desde cero: adaptas una plantilla y la versionas.

Flujo de adaptación (paso a paso)

1

Copia la skill más cercana y cámbiale el nombre con el del cliente: faq-paocia-v1.

2

Cambia solo los puntos de personalización (rol, reglas, categorías, formato). No cambies la estructura.

3

Ejecuta las pruebas de regresión (mismas entradas, comprobar la salida). Solo entonces sube la versión.

Encabezado de versión (pégalo en la parte superior de la skill)

# skill: faq-paocia
# v1.0  2026-06-02  base inicial (5 categorias)
# v1.1  2026-06-09  +categoria "entrega", limiar 0.6 -> 0.65
# v2.0  2026-07-01  schema de saída mudou: +campo "prioridade"
#
# CUSTOMIZAÇÕES deste cliente:
#   - categorias = [pedido, dúvida, entrega, reclamaçêo]
#   - tom = cordial e curto
# TESTES DE REGRESSêO: ver casos/faq-paocia.csv (8 casos)

Cuándo usar

Con cada cliente nuevo o cambio de regla. El control de versiones evita "lo arreglé aquí y se rompió allá" y conserva el historial de decisiones.

Puntos de personalización

  • Convención de nombres (skill-cliente-vX)
  • Dónde guardar el changelog
  • Conjunto de casos de regresión
