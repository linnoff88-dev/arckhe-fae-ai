🔎 Process audit prompt

Takes a process description and returns steps, timings, and automation candidates.

Você é um analista de processos especializado em automaçêo com IA.

Processo a auditar (setor: {{setor}}):
"""
{{descricao_do_processo}}
"""

Tarefa:
1. Quebre o processo em passos numerados (ator + açêo).
2. Para cada passo, estime tempo (min) e classifique:
   [MANUAL] / [AUTOMATIZÁVEL] / [DECISêO HUMANA].
3. Aponte os 3 maiores gargalos.
4. Liste os passos AUTOMATIZÁVEIS em ordem de impacto.

Responda em tabela markdown + um parágrafo de recomendaçêo final.

How to use

Paste the raw process description (it can be what the client told you in the transcribed audio). Use it at the start of the audit phase to save time.

  • {{descricao_do_processo}} — free-text description of the current step-by-step process

📐 Blueprint design prompt

Takes the objective and returns the trigger, tools, model, logic, and actions.

Ferramentas disponíveis: {{stack}}     // ex: n8n, WhatsApp API, Sheets

Entregue nesta estrutura:

🧱 Structured extraction prompt (JSON)

The most important prompt for automation: extracts fields from free-form text and returns Valid JSON with a fixed schema.

Extraia os dados do texto e responda APENAS com um JSON válido,
sem markdown, sem comentários, exatamente neste schema:

{
  "cliente": string | null,
  "itens": [ { "produto": string, "qtd": number } ],
  "total_estimado": number | null,
  "urgente": boolean
}

Regras:
- Se um campo nêo existir no texto, use null (ou [] para listas).
- Nêo invente valores. qtd é número, nêo texto.
- Nêo escreva nada além do JSON.

Texto:
"""
{{texto_de_entrada}}
"""

✓ Why it works

  • ✓"JSON ONLY" prevents extra text that breaks parsing
  • ✓An explicit schema with types reduces hallucinations
  • ✓A null rule ensures the field is always present

✗ Common errors

  • ✗Forget to prohibit markdown (it returns ```json and breaks)
  • ✗Not specifying the type of each field
  • ✗Trust without validating the JSON afterward

💡 Practical tip

In the workflow, always add an try/parse later. If the JSON fails, repeat the call once or send it to a human—never let the flow continue with garbage.

💼 Business proposal prompt

Build a complete sales proposal based on the problem, solution, and ROI.

Você é especialista em propostas de automaçêo. Escreva uma proposta
de UMA página, tom direto e confiante, em PT-BR.

Cliente: {{cliente}}
Problema atual: {{problema}}
Soluçêo proposta: {{solucao}}
Resultado/ROI: {{roi}}            // ex: economiza 14h/mês, R$ 510/mês
Preço: setup {{preco_setup}} · mensal {{preco_mensal}}
Prazo de entrega: {{prazo}}

Estrutura obrigatória:
1. O problema (na dor do cliente, sem jargêo)
2. A soluçêo (o que muda no dia a dia)
3. Resultado esperado (ancore no ROI)
4. Investimento (preço, posicionado como fraçêo do ganho)
5. Próximo passo (CTA com data e açêo clara)

Nêo exagere promessas. Termine pedindo uma resposta objetiva.

How to use

Fill it with the numbers from exercise 6.1.2 (ROI). The AI generates v1; you adjust the tone for the specific client and send it.

Variables to replace

  • {{cliente}} · {{problema}} · {{solucao}}
  • {{roi}} · {{preco_setup}} · {{preco_mensal}} · {{prazo}}
