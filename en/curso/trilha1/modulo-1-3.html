🗺️ The 5-step map

Every strategic automation follows the same path: identify, map, design, build, and commercialize. This module presents the complete map — and shows how each stage becomes a course track, with the practice applied in Track 6.

🔎 Step 1 — Identify

It all starts with the right opportunity. Identify is hunting, within a routine or business, for the repetitive tasks that drain the most time and money — the “10-hour tasks” from Module 1.1. Poor identification dooms the rest of the process.

🎯 What to do in this step

  • •List the tasks that repeat more than twice.
  • •Mark which ones are mechanical and predictable.
  • •Estimate the total time each one takes.

🧭 Where this becomes a path

This step is the heart of the Track 2 — Audit & Mapping, which teaches you how to find the 10-hour task and measure time and cost systematically.

Hunt

Find the right task.

Signals

🗺️ Step 2 — Map

You can’t automate what you don’t understand. Map is documenting the current process step by step — inputs, decisions, outputs — so you can see exactly where automation fits. It’s the bridge between the problem (as-is) and the solution (to-be).

✓ Well-crafted as-is map

  • ✓Show every actual step in the process.
  • ✓Reveals bottlenecks and rework.
  • ✓Shows where automation fits in.

✗ Skip the mapping

  • ✗Automate one part and break another.
  • ✗Discovering exceptions only after it's done.
  • ✗Build in the dark and redo everything.

🧭 Where this becomes a path

Mapping is also part of the Track 2 — Audit & Mapping: diagram the as-is → to-be process and calculate the time savings.

As-is

What the process is like today.

📐 Stage 3 — Design

Design is turning the mapped process into a concrete project: which tools, which AI models, what logic, which prompts, and where the decision points are. A good blueprint makes implementation fast and predictable.

🏗️ What goes into the blueprint

  • •Trigger: what triggers the automation.
  • •Logic: the steps and decisions along the way.
  • •Tools and models: what each part of the work does.
  • •Action: the final result delivered.

🎯 Practical tip

Draw the flow on paper or in a diagram before opening any tool. If the drawing is confusing, the automation will be even worse—the blueprint is where errors are cheap to fix.

🧭 Where this becomes a path

This step is the whole Track 3 — Solution Design: architecture, choice of tools and models, logic, and prompts.

🛠️ Step 4 — Build

Build is where the value finally happens: implementing the automation for real, from trigger to action, with integrations and error handling, until it runs reliably without you around. Solid implementation is what makes the automation work on its own.

1

Build the workflow

From trigger to action

Connect the trigger, steps, and action by following the blueprint. Each part of the diagram becomes a block that does one thing well.

2

Make reliable

Error handling and testing

Anticipate what could go wrong, add checks, and test with real cases. An automation is only worthwhile if you trust it to run on its own.

🧭 Where this becomes a path

Building is all the Track 4 — Build: environment setup, first end-to-end automation, integrations, and reliability.

💰 Stage 5 — Commercialize

The step that closes the loop. Commercialize is turning the automation you built into a service: packaging the deliverable, pricing it based on the value generated, and selling it to clients. Without this, automation is just a hobby that saves you time; with it, it becomes revenue.

📦 From time saved to revenue

  • •Package: turn the automation into a clear offer.
  • •Set a price: charge for the value generated, not the hours spent.
  • •Deliver and scale: repeat the same solution for many clients.

🎯 Practical tip

If the automation saves a client R$ 7,500/year, it’s worth far more than the hours you spent building it. Price it based on the return it generates for the buyer.

🧭 Where this becomes a path

This step is the whole Track 5 — Sales: package it as a service, price it based on the client’s ROI, deliver it, and scale it.
