🔎 Prompt de auditoria de processos

Recebe a descrição de um processo e devolve passos, tempos e candidatos a automação.

Você é um analista de processos especializado em automação com IA.

Processo a auditar (setor: {{setor}}):
"""
{{descricao_do_processo}}
"""

Tarefa:
1. Quebre o processo em passos numerados (ator + ação).
2. Para cada passo, estime tempo (min) e classifique:
   [MANUAL] / [AUTOMATIZÁVEL] / [DECISÃO HUMANA].
3. Aponte os 3 maiores gargalos.
4. Liste os passos AUTOMATIZÁVEIS em ordem de impacto.

Responda em tabela markdown + um parágrafo de recomendação final.

Como usar

Cole a descrição crua do processo (pode ser o que o cliente te contou no áudio transcrito). Use no início da fase de auditoria para ganhar tempo.

📐 Prompt de desenho de blueprint

Recebe o objetivo e devolve trigger, ferramentas, modelo, lógica e ações.

Você é um arquiteto de automações. Desenhe o blueprint para o objetivo
abaixo, usando SOMENTE as ferramentas disponíveis.

Objetivo: {{objetivo_da_automacao}}
Ferramentas disponíveis: {{stack}}     // ex: n8n, WhatsApp API, Sheets
Restrições: {{restricoes}}             // ex: orçamento, latência, dados sensíveis

🧱 Prompt de extração estruturada (JSON)

O prompt mais importante para automação: extrai campos de texto livre e devolve JSON válido com schema fixo.

Extraia os dados do texto e responda APENAS com um JSON válido,
sem markdown, sem comentários, exatamente neste schema:

{
  "cliente": string | null,
  "itens": [ { "produto": string, "qtd": number } ],
  "total_estimado": number | null,
  "urgente": boolean
}

Regras:
- Se um campo não existir no texto, use null (ou [] para listas).
- Não invente valores. qtd é número, não texto.
- Não escreva nada além do JSON.

Texto:
"""
{{texto_de_entrada}}
"""

✓ Por que funciona

  • ✓"APENAS JSON" evita texto extra que quebra o parse
  • ✓Schema explícito com tipos reduz alucinação
  • ✓Regra de null garante campo sempre presente

✗ Erros comuns

  • ✗Esquecer de proibir markdown (vem ```json e quebra)
  • ✗Não dizer o tipo de cada campo
  • ✗Confiar sem validar o JSON depois

💡 Dica prática

No fluxo, sempre coloque um try/parse depois. Se o JSON falhar, repita a chamada uma vez ou mande pro humano — nunca deixe o fluxo seguir com lixo.

💼 Prompt de proposta comercial

Monta uma proposta comercial completa a partir do problema, da solução e do ROI.

Você é especialista em propostas de automação. Escreva uma proposta
de UMA página, tom direto e confiante, em PT-BR.

Cliente: {{cliente}}
Problema atual: {{problema}}
Solução proposta: {{solucao}}
Resultado/ROI: {{roi}}            // ex: economiza 14h/mês, R$ 510/mês
Preço: setup {{preco_setup}} · mensal {{preco_mensal}}
Prazo de entrega: {{prazo}}

Estrutura obrigatória:
1. O problema (na dor do cliente, sem jargão)
2. A solução (o que muda no dia a dia)
3. Resultado esperado (ancore no ROI)
4. Investimento (preço, posicionado como fração do ganho)
5. Próximo passo (CTA com data e ação clara)

Não exagere promessas. Termine pedindo uma resposta objetiva.

Como usar

Alimente com os números do exercício 6.1.2 (ROI). A IA gera a v1; você ajusta o tom para o cliente específico e envia.

Variáveis a trocar

  • {{cliente}} · {{problema}} · {{solucao}}
  • {{roi}} · {{preco_setup}} · {{preco_mensal}} · {{prazo}}
